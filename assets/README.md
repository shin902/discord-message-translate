# Extension icon

Generated with the built-in ImageGen tool. `icon-source.png` is the original generated image; `extension/icons/` contains PNGs resized to 16, 32, 48, and 128 pixels with macOS `sips` for Chrome.

## Generation prompt

Use case: logo-brand. Create one finished square raster app icon for a Discord message translation browser extension. A bold friendly pair of overlapping speech bubbles, one with the exact Latin letter "A", one with the exact Japanese character "あ", communicating translation. Clean flat graphic, thick simple silhouettes, excellent contrast and recognizable at 16 pixels. Use the existing app palette indigo #5865df, white and a small mint accent. Centered mark filling most of a rounded indigo square tile, modest padding, transparent background outside the tile. No Discord mascot or official logo, no other lettering, no mockup, no border frame, no watermark, no tiny decorative detail. Deliver a single 1024x1024 PNG icon.
