# Discord Message Translate

Discord Webのメッセージを、原文を残して翻訳するChrome拡張です。

標準は**APIキー不要のGoogle翻訳**。Ollama・LM Studioなどの**ローカルLLM / OpenAI互換API**にも切り替えられます。APIキーは任意です。

## 導入

1. このリポジトリをダウンロード、または `git clone` します。
2. Chromeで `chrome://extensions` を開き、デベロッパーモードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの **`extension/` ディレクトリ**を選択します。
4. 拡張のアイコンをクリックし、「翻訳を有効にする」をオンにして設定を保存します。翻訳サービスへのアクセス許可を確認します。
5. すでに開いていたDiscord Webを再読み込みします。

インストールにNode.jsやビルドは不要です。初期状態では翻訳は無効、自動翻訳もオフです。Discordデスクトップアプリには対応していません。

## 使い方

- メッセージ下の「翻訳」をクリックすると、原文の下に訳文が表示されます。
- 「表示中のメッセージを自動翻訳」をオンにすると、画面に入った本文を順に翻訳します。
- スクロール中は自動翻訳の開始・訳文の挿入を待機し、操作が止まってから反映します。画面外へ移動した本文の訳文は、再び表示されるまで挿入しません。
- 日本語→日本語など、翻訳先と同じ言語のメッセージはスキップします。
- メッセージが編集されたら、古い訳文を破棄します。自動翻訳中なら再翻訳し、手動なら新しい翻訳ボタンを表示します。
- 原文・メッセージの送信欄は変更しません。コード、ネタバレ、添付画像は翻訳しません。
- 返信先の引用プレビューには翻訳ボタンや訳文を表示せず、翻訳サービスにも送りません。元のメッセージ本文は通常どおり翻訳できます。
- 設定変更は開いているDiscordに反映されます。拡張自体を更新した場合はDiscordを再読み込みしてください。

## 翻訳サービス

| サービス | 設定 | APIキー |
| --- | --- | --- |
| Google翻訳（標準） | サービスを選ぶだけ | 不要 |
| Ollama | `http://localhost:11434/v1/chat/completions` とインストール済みモデル名 | 通常不要 |
| LM Studio | `http://localhost:1234/v1/chat/completions` とロード済みモデル名 | サーバーの認証設定に応じて任意 |
| その他のOpenAI互換API | HTTPSのChat Completions URLとモデル名 | サービスが要求する場合のみ入力 |

ローカルLLMは先にサーバーを起動し、翻訳可能なモデルを用意してください。URLは `/v1/chat/completions` まで入力します。キーが空欄ならAuthorizationヘッダーを送りません。Responses API専用サーバーは対象外です。

Googleは `translate.googleapis.com/translate_a/single` の公開エンドポイントを利用します。**公式Cloud Translation APIの無料枠を使う実装ではなく、無制限・無料での継続提供を保証するものではありません。** 制限や仕様変更で使えなくなる場合があります。拡張独自の日次回数制限はありません。有料APIを設定した場合は、そのサービスの料金が適用されます。

## 同じ言語をスキップする仕組み

1. URL、コードなどを除いた本文について、翻訳対象の文字があるか確認します。
2. Chrome内蔵の `chrome.i18n.detectLanguage` が信頼できる結果を返した場合、翻訳先と同じ言語ならAPIを呼びません。短いかな主体の日本語も事前に除外します。
3. 不確かな場合は翻訳サービスへ送ります。Googleが返す検出言語が翻訳先と同じなら訳文を表示しません。原文と同じ訳文も表示しません。

漢字があるだけで日本語とは判定しません。中国語や英語主体の混在文を一律に除外する方式は避けています。ただし、短文・固有名詞・混在文の言語判定は完全ではなく、日本語がサービスへ送られる場合もあります。OpenAI互換APIは標準の言語検出フィールドがないため、Chromeの判定と原文一致を利用します。

## データ・権限

- 翻訳対象の本文だけを選択した翻訳サービスへ送ります。外部Googleサービスを使いたくない場合はローカルLLMを指定してください。
- Discordの認証トークン、Cookie、送信欄の下書きは取得しません。メッセージの送信もしません。
- APIキーを含む設定は `chrome.storage.local` に保存し、同期しません。暗号化保管ではありません。
- ストレージを拡張の信頼されたコンテキストだけに制限し、Discord上のcontent scriptには有効・自動翻訳・翻訳先の設定のみを渡します。
- Discordのホスト権限は本文表示と設定反映に使用します。翻訳先は設定保存時に、そのホストへのオプション権限を要求します。HTTPS全体を一括で許可する設計ではありません。
- HTTPは `localhost` と `127.0.0.1` のみ許可します。APIリダイレクトを追跡せず、通信にCookieを付けません。
- 翻訳結果をHTMLとして解釈しません。本文・訳文の永続保存やアクセス解析は行いません。
- 最大300件のメモリ内キャッシュとリクエスト共有で重複を抑え、翻訳処理は同時2件に制限します。キャッシュは設定変更やサービスワーカー停止で消えます。

## 開発・検証

Node.js 22以上を使用します。開発用依存関係はテストのDOM環境のみで、拡張の実行時依存はありません。

```sh
npm ci
npm run check
npm test
```

言語判定、APIレスポンス・認証ヘッダー、キャッシュ、同時実行制限、設定変更時の待機処理破棄、送信元の検証、DOM上の編集追従・可視範囲・XSS防止をテストしています。CIでも同じチェックを行います。

ブラウザでの確認項目:

1. 英語は翻訳され、日本語はスキップされること。
2. 中国語や日英混在文が漢字だけを理由に除外されないこと。
3. スクロール、新着、編集、チャンネル切り替えで表示が追従すること。
4. 自動翻訳オフではクリックするまで通信しないこと。
5. サーバー停止・権限拒否時はエラーが表示され、ボタンで再試行できること。
6. Ollama / LM Studioでキー空欄のまま動作すること。

Googleへのサンプル文リクエストと、モック環境の設定画面・DOM動作を検証しています。実際のDiscord画面への拡張インストールおよび実モデルを使うローカルLLM接続は別途確認が必要です。DiscordのDOM変更により本文検出が動かなくなる可能性があります。

## 構成

```text
extension/
  manifest.json       Chrome Manifest V3
  background.js       送信元検証・設定・翻訳受付
  content.js          Discord本文の監視と訳文表示
  options.*           設定画面
  lib/
    settings.js       設定検証と権限の送信先
    language.js       同言語・翻訳対象の判定
    providers.js      Google / OpenAI互換クライアント
    engine.js         キュー・重複抑制・キャッシュ
tests/                Node.js + jsdom テスト
```

実装上の参照: [Chromeの言語判定API](https://developer.chrome.com/docs/extensions/reference/api/i18n)、[拡張のクロスオリジン通信](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)。
